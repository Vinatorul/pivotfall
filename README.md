# Pivotfall

Pivotfall — одноэкранная action-puzzle-аркада, где врагов устраняют не уроном,
а самой ареной: сталкивают в ямы и шипы, сбрасывают с платформ и заманивают
под действие механизмов. Вражеская атака смертельна для игрока, но может
отбросить другого врага или активировать шарнир — опасность одновременно
становится инструментом решения.

## [Играть в браузере →](https://vinatorul.github.io/pivotfall/)

Web-версия запускается без установки. На телефоне удобнее играть в
горизонтальной ориентации.

## Текущий статус

- проект работает на Godot 4.6.x; команды ниже и CI проверены на Godot 4.6.1;
- доступны Web-версия и запуск на компьютере, а в мобильном браузере
  автоматически
  появляются экранные кнопки;
- кампания полностью описана данными и состоит из 16 арен; последняя —
  **Arena 16 / Штурм**;
- главное меню поддерживает сохранение прогресса, выбор уже открытых арен и
  replay без изменения сохранения;
- встроенный редактор позволяет собрать арену, проверить её и обменяться
  уровнем через Import/Export;
- проект остаётся graybox-прототипом без финальных ассетов.

Прогресс хранится локально. В Web-версии сохранение связано с данными
конкретного браузера и не переносится между устройствами автоматически.

## Как играть

Цель каждой арены — устранить всех врагов окружением. У противников нет полосы
здоровья, а удар игрока только отбрасывает их или приводит в действие механизм.
Касание врага, его рывок или снаряд, падение в яму и шипы сразу завершают
попытку.

Начните с `НОВАЯ ИГРА` в главном меню. После прохождения арен можно открыть
`ВЫБОР АРЕН` и переиграть любую доступную арену: постоянный прогресс при этом
не меняется.

### На компьютере

- `A` / `D` или `←` / `→` — движение;
- `W`, `↑` или `Space` — прыжок;
- `X` или `J` — короткий удар;
- `R` — начать текущую арену заново;
- `Esc` — открыть или закрыть паузу;
- `H` или кнопка `?` — подсказка текущей арены.

Подсказка открывается только по запросу. Во время чтения игра стоит на паузе.
В меню паузы можно посмотреть управление, начать арену заново или выйти в меню.

После подбора усилителя повторное нажатие прыжка в воздухе выполняет один
дополнительный прыжок.

В меню выбор перемещается клавишами `↑` / `↓` или `W` / `S`, а
`Enter` и `Space` подтверждают действие.

### Мобильный браузер

- `<` / `>` — движение;
- `JUMP` — прыжок;
- `HIT` — удар;
- `II` — пауза, `?` — подсказка арены.

Движение можно удерживать одновременно с прыжком или ударом. Главное меню,
выбор арен, пауза и экран завершения управляются касаниями.

## Системы игры

- **Патрульный** ходит по платформе и разворачивается у края. Само касание его
  корпуса смертельно.
- **Толкач** предупреждает о рывке. Промах открывает окно для удара, а сам
  рывок может сдвинуть другого врага или задеть шарнир.
- **Стрелок** ведёт прицел, затем фиксирует направление и стреляет. Его снаряд
  смертелен для игрока, но действует на врагов и механизмы.
- Удар игрока не наносит урон: он сообщает врагам фиксированный импульс и
  активирует шарниры.
- Ямы и шипы устраняют и игрока, и врагов.
- Шарниры управляют включаемыми платформами, катапультами, лифтами и воротами.
  Нажимная плита удерживает связанную платформу или ворота, пока на ней стоит
  игрок или враг.
- Усилитель двойного прыжка открывает один дополнительный прыжок в воздухе;
  после приземления он снова доступен до перезапуска арены.

## Редактор и обмен уровнями

На компьютере выберите `РЕДАКТОР УРОВНЕЙ` в главном меню. Редактор доступен и
в Web-версии на компьютере; на устройствах с сенсорным экраном кнопка скрыта.

Основной цикл работы:

1. Соберите арену из геометрии, врагов, опасностей и механизмов.
2. Нажмите `ТЕСТ F5`, чтобы запустить неизменяемый снимок черновика.
3. Нажмите `Esc`, чтобы вернуться в редактор с прежними Undo/Redo и
   выделением.
4. Выберите `Файл → Экспорт JSON`, чтобы скачать проверенный
   `<level_id>.json` в Web.
5. Выберите `Файл → Импорт JSON`, чтобы выбрать JSON-файл и добавить уровень
   в библиотеку.

Ошибки в данных блокируют сохранение и тест. Импортированный файл проходит ту
же проверку, что встроенные уровни, и не может подключить произвольный скрипт
или сцену.

Формат JSON, инструменты, ограничения и безопасное хранение подробно описаны
в [документе о редакторе](docs/LEVEL_EDITOR.md).

## Локальный запуск

Нужен Godot 4.6.x. Команды ниже проверены на версии 4.6.1, которую использует
CI.

```sh
git clone https://github.com/Vinatorul/pivotfall.git
cd pivotfall
godot --path .
```

Другой вариант — открыть `project.godot` в редакторе Godot и нажать `F5`.

## Разработка и проверки

После свежего checkout сначала импортируйте ресурсы и реестр `class_name`:

```sh
godot --headless --path . --import
```

Запуск всех 37 smoke-тестов:

```sh
bash tests/run_smoke_tests.sh
```

Один или несколько выбранных тестов передаются runner аргументами:

```sh
bash tests/run_smoke_tests.sh tests/campaign_smoke.gd
```

GitHub Actions выполняет тот же импорт и smoke-suite, затем проверяет Web
export. Сборка из `main` публикуется на GitHub Pages только после успешных
проверок.

Подробности о runner, локальный Web export, устройство CI, архитектурные
контракты и диагностика находятся в
[руководстве разработчика](docs/DEVELOPMENT.md).
