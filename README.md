# Retro action-puzzle research

Локальный исследовательский репозиторий для выбора небольшого проекта,
вдохновлённого играми Game Boy, Game Boy Color и NES.

## Решение

Основное направление — самостоятельная action-puzzle-игра в духе
[Mole Mania](https://www.nintendo.com/en-gb/Games/Game-Boy/Mole-Mania-641354.html):
компактные комнаты, два слоя пространства и задачи на перемещение объектов.

Это не ремейк и не fan game. Проект должен использовать собственные название,
мир, персонажей, уровни, интерфейс, графику, музыку, звуки и код.

Планируемые ограничения:

- движок: Godot 4;
- целевые платформы: ПК и Web;
- срок разработки: 1–3 месяца свободного времени;
- предполагаемый объём: 12–20 оригинальных комнат;
- первый этап: только исследование, без игрового кода и Godot-проекта.

## Исследование

Сравнение 12 подходящих игр, итоговый рейтинг, рекомендуемый масштаб и
IP-ограничения находятся в [RESEARCH.md](RESEARCH.md).

## Следующий этап

Перед прототипированием нужно отдельно определить собственный сеттинг,
центральный twist и визуальное направление. После этого можно создать
минимальный Godot-проект и проверить механику на 3–5 тестовых комнатах.

Лицензия пока не выбрана: в репозитории нет программного кода или игровых
ассетов.
