# Одноэкранная action-puzzle-аркада

Локальный репозиторий небольшого образовательного проекта на Godot 4. После
исследования игр Game Boy, Game Boy Color и NES направление уточнено до
самостоятельной одноэкранной аркады.

## Решение

Игрок не наносит прямой урон: его атака отбрасывает противников и активирует
шарниры, которые выключают, поворачивают или перемещают платформы. Победа требует
вытолкнуть врагов в ямы и ловушки. Вражеские атаки подчиняются тем же правилам,
поэтому их можно провоцировать и использовать для перестройки арены.

Ключевое отличие от Bubble Bobble- и Snow Bros.-подобных игр: враги не
превращаются в переносимые объекты. Окружение служит оружием, а опасные действия
противников одновременно становятся инструментами решения.

Планируемые ограничения:

- движок: Godot 4;
- целевые платформы: ПК и Web;
- срок вертикального среза: 6–8 недель свободного времени;
- объём MVP: восемь одноэкранных арен;
- три типа противников и три типа платформ;
- первый прототип — graybox без финальных ассетов.

Это не ремейк и не fan game. Проект должен использовать собственные название,
мир, персонажей, уровни, интерфейс, графику, музыку, звуки и код.

## Следующий этап

Создать минимальный Godot-проект и за первую итерацию проверить бег, прыжок,
фиксированное отбрасывание, патрульного, яму, шарнир и включаемую платформу на
трёх graybox-аренах. Следующие системы добавляются по одной только после того,
как основной цикл читается и ощущается честным.

Сеттинг, публичное название и визуальное направление намеренно отложены до
проверки механики. Лицензия пока не выбрана: в репозитории всё ещё нет
программного кода или игровых ассетов.
