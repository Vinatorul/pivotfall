# Одноэкранная action-puzzle-аркада

Учебный проект на Godot 4: компактные арены, отбрасывание противников и
перестраиваемые платформы. Сейчас реализован только минимальный каркас с
управляемым персонажем.

## Запуск

1. Открыть `project.godot` в Godot 4.
2. Нажать `F6` или `F5`.

Из терминала:

```sh
godot --path .
```

Проверено на Godot 4.6.1.

## Управление

- `A` / `D` или `←` / `→` — движение;
- `W`, `↑` или `Space` — прыжок.

## Текущий состав

- одна graybox-арена размером 960×540;
- персонаж с ускорением, торможением, гравитацией и прыжком;
- стены, потолок, пол и одна тестовая платформа;
- без атак, противников, ловушек и финальных ассетов.
